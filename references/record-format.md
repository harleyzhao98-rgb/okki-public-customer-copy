# 输出与断点格式

沿用用户已有格式优先；新任务可用以下字段：

```text
公司名称：<源值>
客户编号：<源值；必填，作为去重键>
客户阶段：<源值>
分组：<源值或未提供>
公海分组：<源值>
跟进人：<源值或已核实的公海状态>
原跟进人：<源值或未提供>
客户来源：<源值或未提供>
国家/地区：<源值或未提供>
公司网址：<源值或未提供>
联系人：<逐个记录全部当前联系人及对应邮箱>
邮箱：<源值或未提供>
创建时间：<源值或未提供>
最近联系时间：<源值或未提供>
WhatsApp：<当前专用字段号码或未提供>
WhatsApp核对状态：<待核对 / 已核对：有号码 / 已核对：未提供 / 异常待核对>
```

每个联系人分别关联邮箱、WhatsApp和核对结果，不把不同人的字段合并。时间不换算、不补零、不用创建时间替代最近联系时间。缺失分组不能默认“未分组”，两者含义不同。

索引至少保存客户编号、全部模板字段、详情来源 URL、联系人核对状态、WhatsApp核对状态。资料与核对状态分离；不要默认填充国家、网址、跟进人或阶段。

进度文件最小内容：

- 目标范围及页面显示总数（可变化，需核对差异）
- 已保存唯一编号数、联系人已核对数、WhatsApp已核对数
- 完整完成的页码，部分完成页的已保存编号
- 下一页或下一客户入口、最后成功编号
- 缺失/异常字段待办与当前登录或工具阻碍
- 主文稿与索引路径、最近一致性校验结果

若客户总数或排序发生变化，不直接把页码等同于完成数量；保留编号集合，核实范围变动并补齐缺口。样例中的占位符不能写入真实客户文稿。
